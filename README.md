# davecriswell.com

My personal website: plain HTML and CSS, hosted on GitHub Pages.

The website lives in the `docs/` folder, which is the only folder GitHub Pages publishes.

- `docs/index.html`: Home
- `docs/work/index.html`: Work (case studies)
- `docs/playbook/index.html`: Playbook & AI
- `docs/about/index.html`: About
- `docs/writing/`: Writing (built, not linked yet)
- `docs/style.css`: all the styling (colors and fonts are at the top)

To preview it locally, run `python3 -m http.server` inside `docs/` and open http://localhost:8000.
