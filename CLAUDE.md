# davecriswell.com

Dave Criswell's personal website. Plain HTML and CSS, no build step, hosted on GitHub Pages.
Dave is new to development and uses this project to learn Claude Code and GitHub, so explain changes in plain language.

## Files
- `index.html` is the home page. All sections live here.
- `style.css` holds every style. Colors and fonts are tokens at the top in `:root`.
- `writing/` holds one HTML page per essay. Each links `../style.css`.

## Positioning
"I build the systems underneath revenue: the CRM, the data, the automation, and the reporting that tells you what's actually working."
Audience: potential employers and partners. They should understand what Dave does and who he is as a person.

## Voice
First person, plain-spoken, calm, and warm, with real empathy for the people who use the systems. No hype. Describe status honestly (for example "automated through X, manual after that").

## Design
Inspired by m3ka.com (warm off-white, serif headings, mono labels, thin rules) and chester.how (a large serif intro with key words highlighted). No playful toggles for now. No photo yet.
